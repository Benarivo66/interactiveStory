# Overview

Using Javascript to work with ES6 array methods, recursion, object, third party libraries and error handling

The program tells different possible stories based on the user input at intervals from a common starting point. 

The purpose is to see how Javascript can be used interactively and recursively to the delight, curiosity and satisfaction of potential users
